# 🎨 AI Canvas Studio (OpenAI GPT-4o & DALL-E 3)

전문적인 드로잉 캔버스(브러시, 색상, 다중 레이어 시스템)와 **OpenAI(GPT-4o, DALL-E 3)** 기반의 AI 아트 조수 및 **AI 캐치마인드(그림 맞추기 게임)**를 즐길 수 있는 웹 스튜디오입니다.

---

## 🌟 주요 기능

### 1. 🖌️ 전문적인 드로잉 도구
- **다양한 브러시**: 펜(부드러운 베지어 곡선 보정), 연필(스케치 흑연 질감), 반투명 마커/형광펜, 부드러운 에어브러시, 지우개
- **도형 및 채우기**: 직선, 사각형, 원/타원(테두리/채우기), 페인트통(Flood Fill)
- **정밀 색상 컨트롤**: HTML5 컬러 피커, 18색 퀵 프리셋 팔레트, 스포이트(Eyedropper)
- **브러시 옵션**: 굵기 조절(1~100px), 불투명도 조절(5~100%), 실시간 브러시 프리뷰

### 2. 📑 멀티 레이어 (Multi-Layer) 관리 시스템
- 레이어 추가(➕), 복제(📋), 삭제(🗑️), 아래 레이어와 병합(⬇️)
- 레이어 순서 변경(▲/▼), 가시성(👁️) 및 레이어 잠금(🔒)
- 레이어별 개별 투명도(Opacity 0~100%) 조절 및 실시간 썸네일 미리보기

### 3. 🤖 OpenAI 전용 AI 기능 (GPT-4o & DALL-E 3)
- **✨ 새 그림 그리기**: DALL-E 3 고해상도(1024x1024) 텍스트-투-이미지 생성
- **🎨 현재 그림 수정**: 캔버스 스케치를 GPT-4o Vision이 분석하여 원하는 화풍/디테일로 DALL-E 3 재창작
- **💡 그림 피드백**: GPT-4o가 형태, 구도, 색감에 대한 전문적이고 따뜻한 미술 코칭 제공
- **캔버스 원클릭 적용**: 생성/수정된 이미지를 `➕ 새 레이어로 추가`하거나 `🔄 현재 레이어 덮어쓰기` 가능

### 4. 🎮 AI 캐치마인드 (내가 그린 그림 맞추기 게임!)
우측 하단 위젯의 **[🎮 AI 그림 맞추기]** 탭에서 AI와 퀴즈를 즐길 수 있습니다:
- **🎯 제시어 맞추기 모드**:
  - AI가 동물, 사물, 음식, 자연, 랜드마크 등 다양한 제시어와 힌트를 출제합니다.
  - 그림을 그리고 **[🔍 AI에게 맞혀보라고 하기!]**를 누르면, GPT-4o Vision이 정답 판정(유사도 %), 관찰된 특징, 재치 있는 코멘트를 남깁니다.
  - 정답 시 100점 + 연속 정답 콤보 점수를 획득합니다!
- **🎨 자유 퀴즈 모드**:
  - 자유롭게 그린 그림을 보고 AI가 1위, 2위, 3위 추측 단어와 특징을 알려줍니다.

### 5. 🔑 안전한 OpenAI API 키 설정
- 상단 **[⚙️ OpenAI API 키 설정]**에서 `sk-...` 키를 입력하고 바로 연결 테스트를 할 수 있습니다.
- 브라우저 로컬 저장(LocalStorage) 또는 세션 저장(SessionStorage) 선택 가능하며, 외부 서버로 유출되지 않습니다.
